El seguent pas es arrencar els contenidors manualment:

1. L’ordre per encendre els connectors és Taiga → Github → Sheets.

docker-compose up -d qrconnect_[taiga/github/sheets]_[pes/asw/amep].

2. Per veure si els connectors s'executen bé cal inspeccionar els seus logs.

docker logs -f [container id].

3.Encendre el contenidor qreval

docker-compose up -d qreval.
